# jacksun-bin-scripts

孙哥本机常用的一批小脚本（2026-11-12 备份）。

| 文件 | 作用 |
|---|---|
| `bark` | 通过 Bark 给 iPhone 发推送 |
| `chatgpt-proxy` | ChatGPT 本地代理启动脚本 |
| `claude-fcp` | 唤起 Final Cut Pro 相关流程 |
| `monitor-uuremote.sh` | UU 远程状态监控 |
| `screen-upload.sh` | 屏幕截图上传到自建监控页 |
| `sysreport` | Mac 状态采集（CPU/容量/网速/电池），每 30 秒上报给 FuBoTV 天气屏 |
| `upload_kodbox.py` | 可道云上传 |
| `aiplace` | **全盘落盘入口**：任何文件自动归到标准区，`sweep` 查散落、`where` 查位置、`status` 看体积 |
| `claude-bin/ds` | 把子任务派给 DeepSeek 跑 |
| `claude-bin/trust-cwd.py` | 自动标记 Claude Code 的工作目录信任弹窗 |
| `claude-scripts/backup-la2-vps.sh` | 备份海外 VPS |
| `claude-scripts/gen-la-vps-config.py` | 生成 VPS 配置 |

`brick`、`check-xdr` 已包含在 `hardware-hacks` 仓库，未重复。
